# 音乐来源与账号

`scripts/start-local.ps1` 同时启动后端与独立的网易云、酷狗音乐接口，端口分别为 8890、4002、5002。不会替换或终止机器上原来的音乐服务。此机器可仅读原安装目录中的 Node 依赖；全新安装先运行 `scripts/install-music-sidecars.ps1`，依赖版本由 lock 文件固定。

酷狗页提供“连接酷狗账号”。使用酷狗 App 扫描二维码并在手机上确认后，PianoFlow 自动保存这次登录的 Cookie 到当前项目 `runtime/kugou-cookie.txt`。网页只收到登录状态；不会读取其他浏览器账号，也不会把 Cookie 写进示例或交付文件。二维码过期可重新获取。扫码只授权正常账号登录，歌曲仍由平台决定播放权限。

网易云页也提供“连接网易云音乐账号”，使用网易云 App 扫码确认后，自动保存本次登录到当前项目 `runtime/netease-cookie.txt`。平台按账号权限取播放地址。无权限的歌曲可能只有试听音频；曲库会标记“本地试听”，时长来自实际音频。账号有完整播放权限后，再次下载会以正常完整音频替换旧试听。PianoFlow 不读取浏览器数据库。

B 站保存公开设备标识到当前项目 `runtime/bilibili-cookie.txt`。若平台要求登录，可以将本人正常导出的 B 站 Netscape Cookie 文件配置为 `PIANOFLOW_YTDLP_COOKIE_FILE`。搜索与下载共享这份会话，刷新设备标识时保留账号 Cookie。真实平台风控会显示清楚的等待提示。

下载时同时保存封面图片到音频缓存。曲库通过本地 `/api/cache/cover/<key>` 提供封面，之后播放不再依赖远端图片地址；清理音频会一起清理封面。临时封面获取失败时保留原封面 URL 作为回退。

`runtime/`、缓存音频、账号文件和日志均为私有运行数据，不应提交、发布或加入公开演示。
